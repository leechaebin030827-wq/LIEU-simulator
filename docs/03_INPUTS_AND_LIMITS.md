# 구현 전에 확인할 정보 — 우선순위 질문지

**웹 편집기 제작은 지금 당장 시작할 수 있다.** 그러나 실제 기구 움직임·광학·배선에 충실한 물리 시뮬레이션과 장치 연동은 아래 정보가 있어야만 정확히 만들 수 있다. 값이 없다면 `UNKNOWN/null`로 유지하고 프리뷰 설정과 분리한다.

## P0 — 먼저 알려주면 리그 구조를 확정할 수 있는 10가지

| ID | 확인해야 할 내용 | 원하는 답변 형식/예 | 이 답을 알아야 하는 이유 |
|---|---|---|---|
| **M01** | 실제로 움직이는 자유도 총 몇 개? 레일 이동, 도넛 **수직축 회전(Yaw)**, 도넛 좌우 **기울임(Tilt)**이 모두 실존하나? | `레일 X 1축 / 도넛 Yaw 1축 / Tilt 1축 / 추가 0` | GLB에는 joint 정보가 없으므로 세 축이 모두 구동된다고 단정 불가 |
| **M02** | 각 자유도를 움직이는 **정확한 모터 제품명과 수량**? | `Tilt: DYNAMIXEL XL330-M288-T ×1`, `Rail: ...`, `Yaw: ...` | 전용 encoder 단위와 명령 범위·드라이버 결정 |
| **M03** | 도넛이 기울 때 **무엇이 함께 기울어지는가**? 외장/눈/중앙 projector/24 NeoPixel/기둥/베어링 중 체크 | `외장+눈은 기울고, 프로젝터+24LED는 수평 유지` | 가장 중요한 링크/관절 owner 결정 |
| **M04** | 도넛이 Yaw할 때 **무엇이 회전하는가**? (상·중·하 베어링 각각 고정/가동) | 부품별 `fixed / yaw / tilt` | 베어링과 모터 케이스/혼을 잘못 회전시키지 않기 위해 |
| **M05** | 각 축의 **하드스톱/허용 범위**? | `Rail 0~220mm`, `Yaw -60~+60°`, `Tilt -18~+18°` (예시이며 실측값 아님) | 슬라이더 범위, invalid keyframe 검사 |
| **M06** | 각 모터의 **HOME(0) 위치**와 +회전 정의? | `도넛 수평 = 0°, 왼쪽 기울기 = +도` | 프리뷰와 실물 커맨드 간 부호/원점 일치 |
| **M07** | 각 축의 허용 **최대 속도 / 가속도**, 가능하면 jerk | `Tilt max 25°/s, accel 50°/s²` (예시) | 실제 동작 가능한 키프레임 시간/곡선 계산 |
| **M08** | 레일 구동은 **무슨 방식**? (벨트, 리드스크루, 리니어 액추에이터, 수동, 기어) + 엔드스톱/원점센서 유무 | `벨트+스테퍼 / 리미트 스위치 양쪽 / ...` | X 이동 단위·안전·원점 복귀 검증 |
| **M09** | 프로젝터/24LED는 틸트축과 함께 움직이나? 프로젝터 렌즈는 실제로 어느 방향을 비추나? | `프로젝터는 중앙 고정, 광축 -Y` | 바닥 투사 위치/조명 일관성 결정 |
| **M10** | 3D CAD/Fusion에서 **joint/축 피벗 원점** 혹은 부품 연결도 제공 가능? | Fusion `Joint Origin` 좌표/스크린샷 / STEP/F3D | AABB 중심은 정확한 회전축이 아님 |

M01–M10에서 **M01, M03, M04, M05, M06, M10**이 특히 중요하다. 현재 GLB만으로 확정할 수 없다는 점을 Codex에 명시하자.

## P3 — 실제 장치 제어로 확장할 때 추가로 반드시 필요

- 제어 보드 모델과 연결 구조: Arduino UNO, ESP32, USB Serial, ROS2, DYNAMIXEL TTL/RS485, WebSerial/WebSocket 등.
- 모터별 ID·baudrate·control table, operating mode(Position/Extended position/Velocity), gear ratio, encoder ticks/degree, current limit 및 과부하 경고 정책.
- 전원 계통 분리, 서보 stall 토크/최대 부하, 안전 E-stop, 사람과 접촉 가능성이 있는 부위의 마진, 레일 양단 hard limit.
- PC↔장치 통신 주기와 ACK/timeout, 재접속·중립 상태·홈 동작. **시뮬레이터의 출력값이 실물에서 안전하다는 보장이 없으므로 calibration 완료 전 실제 송신은 금지**.

## 현재 제공되는 preview-only 조작 범위 (실물 사양 아님)

| 채널 | 임시 범위 | 임시 최대 속도 | 임시 최대 가속도 |
|---|---:|---:|---:|
| Rail X | **-0.25 ~ 0 m** | 0.06 m/s | 0.12 m/s² |
| Yaw Y | **-45° ~ +45°** | 30°/s | 90°/s² |
| Tilt Z | **-15° ~ +15°** | 20°/s | 60°/s² |

이 수치는 모델이 어떤 움직임을 표현할지 검토하는 데만 쓴 **임의의 시연용 초깃값**이다. 실물 기구 한계·충돌/케이블·동력학에 대한 검증 근거가 없으므로 HardwareAdapter가 절대 사용해서는 안 된다.
