# Yaw 회전 부품 묶음 (LIEU_for_web.glb, 사용자 확인 완료)

> 근거는 GLB 메시의 월드 좌표에서 잰 부품 사이 최소 간격(mm)이다. 간격 0.2mm 이하는 '붙어 있음'으로 봤다. 아래 회전/고정 묶음은 사용자가 실물과 맞다고 확인했다(2026-10-29). 볼트, 조인트 단위의 조립 확인은 아니다.

## 요약 (확정)

- **회전 묶음 (링 기어 쪽):** 링 기어(3D 베어링 하부), 루 하부, 루 하부 (2), 눈 LED 가이드, 눈 보드 2개, Body154
- **고정 묶음 (위쪽, 피니언 모터 쪽):** 3D 베어링 상부, 3D 베어링 중부, 루 상부, 피니언 모터 케이스 일체, 피니언
- **중앙 고정 구조 (링과 닿지 않음, 간격 28mm 이상):** 기둥, LED 부착부, Body7, Miniray_Beam, XM430 더미, LIEU 모터 샤프트, 틸트 샤프트 2개

## 확정과 미확정

- 확정 (사용자): 위쪽 고정, 아래쪽 회전.
- 형상으로 확인: 링 기어 바깥 톱니 118개, 피니언 17개, 중심 거리 88mm. 이름의 `1.3mm`를 모듈로 가정하면 두 기어의 피치 반지름 합이 87.75mm로 모델의 88mm와 맞는다. 단, 잇수는 아직 실물과 대조하지 않았다.
- 확정 (사용자 확인): 위 회전/고정 묶음.
- 미확정:
  - 3D 베어링 중부(볼 또는 롤러 케이지로 보임)는 베어링 속도 관계상 링의 절반 정도로 돌 수 있으나, 미리보기에서는 고정으로 둔다.
  - 회전 방향 부호와 원점(`originOffsetDeg`).
  - 눈, 중앙 LED의 배선이 회전 묶음과 어떻게 이어지는지(케이블 감김 한계).
  - 피니언 모터 모델과 통신 방식. 모델의 후보 `XL,XC-330`이 실제 구동 모터인지.
